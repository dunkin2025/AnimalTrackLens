# Contributing

Thank you for your interest in Animal Behavior Detection.

Contributions can include:

- Computer vision
- Machine learning
- Dataset development
- Video annotation
- Animal behavior expertise
- Model evaluation
- Documentation
- Testing
- Website development

## Before contributing

Please describe the problem, proposed change, or experiment clearly.

For behavioral datasets, document:

- Species
- Behavior definition
- Video source
- Annotation method
- Time resolution
- Dataset limitations
- Permissions and licensing

## Scientific responsibility

Do not present an AI classification as established animal behavior without appropriate validation.

When possible, retain the original video context and human-reviewed annotations so that model results can be independently evaluated.
