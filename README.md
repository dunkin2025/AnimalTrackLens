# Animal Behavior Detection

AI-powered observation for wildlife research, conservation, and animal welfare.

## Project website

This repository contains the static GitHub Pages website for the Animal Behavior Detection project.

Replace `ourprojectname` in the links with the actual GitHub repository name.

## Files

- `index.html` — main website
- `style.css` — layout, typography, responsive design
- `script.js` — mobile navigation and dynamic year
- `README.md` — project information

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.

For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

1. Push these files to your GitHub repository.
2. Open **Settings → Pages**.
3. Select the branch containing the website.
4. Select `/ (root)` as the folder.
5. Save.

The site can then be served from the repository's GitHub Pages address.

## Important

The animal detection shown on the homepage is a visual demonstration only. It is not connected to a real camera or AI model.

When the project has a working model, the demo panel can be connected to real inference output.

## Scientific principle

The project should distinguish between:

- animal detection
- individual tracking
- observable behavior classification
- behavioral pattern analysis
- scientific interpretation

AI output should be validated against human or expert annotations before being treated as research evidence.
